# Appendix — Style Consistency Notes

## To match all characters to the same art style, append one of these to every prompt:

**Default (semi-realistic painterly):**
```
fantasy medieval digital painting, clean lineart, flat neutral lighting
```

**Anime/VN style:**
```
anime style, visual novel character art, cel shaded, clean lines, light shading
```

**Semi-realistic detailed:**
```
concept art, artstation, detailed rendering, painterly
```

## Consistency Tips
- Generate Aldric Day 0 first and lock the style
- Use the same seed/model settings for all characters
- All characters should share the same background (plain white), lighting (flat neutral), and framing (perfectly centered, symmetrical)
- Generate each character's front clothed view first, then use it as reference for the other views
- Maintain the same level of anatomical detail across all characters
- All prompts include "solo figure" to prevent multi-character generation
